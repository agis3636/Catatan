Tipe atau edisi sistem operasi Windows modern (seperti Windows 10 dan 11) yang biasa muncul saat proses instalasi.

### Perbandingan Edisi Windows

Berikut adalah perbedaan utama dari setiap jenis edisi Windows:

<img width="765" height="274" alt="Image" src="https://github.com/user-attachments/assets/4d89a40f-22ad-490a-b184-6f446724016c" />

| Tipe / Edisi Windows | Target Pengguna | Fitur Utama & Perbedaan |
| --- | --- | --- |
| **Home** | Pribadi / Pelajar | Versi paling dasar dan ringan. Cocok untuk *gaming*, *browsing*, dan tugas harian. Tidak memiliki sistem keamanan jaringan kelas bisnis. |
| **Pro** | Profesional / Bisnis Kecil | Memiliki semua fitur Home, ditambah fitur kontrol sistem lanjutan: *BitLocker* (enkripsi partisi/flashdisk), *Group Policy* (mengatur hak akses komputer), dan *Hyper-V* (membuat mesin virtual bawaan). |
| **Pro for Workstations** | Desainer 3D / Ilmuwan Data | Didesain untuk komputer dengan spesifikasi "monster". Mendukung prosesor kelas *server* (Intel Xeon / AMD Epyc), RAM hingga 6 TB, dan sistem file ReFS yang tahan terhadap kerusakan data berat. |
| **Enterprise** | Perusahaan Besar | Fitur keamanan siber paling maksimal. Administrator IT dapat mengontrol, membatasi, dan melacak ribuan komputer karyawan dari jarak jauh. Tidak dijual eceran, melainkan sistem lisensi volume (borongan). |
| **Education / Pro Education** | Sekolah / Universitas | Fiturnya sama persis dengan edisi *Enterprise* atau *Pro*, namun disesuaikan untuk institusi pendidikan dengan harga lisensi yang jauh lebih murah. Fitur hiburan (seperti *games* bawaan) sering dinonaktifkan secara otomatis. |
| **Varian "N"** | Wilayah Eropa | Varian khusus (contoh: *Home N*, *Pro N*) yang dibuat karena aturan monopoli hukum Uni Eropa. Versi ini datang tanpa aplikasi media bawaan seperti Windows Media Player, Skype, atau Voice Recorder. |
| **LTSC / LTSB** | Mesin Industri / Medis / ATM | *Long-Term Servicing Channel*. Versi paling stabil dan ringan. **Analogi:** Seperti mobil operasional tambang, tidak butuh AC atau radio (Cortana, Edge, dan Microsoft Store dihapus), yang penting sistem tidak pernah *error* dan terus mendapat pembaruan keamanan hingga 10 tahun tanpa perubahan tampilan. |

### Penjelasan Tambahan

**Home Single Language:** Ini adalah turunan dari versi Home yang sering ditemui sebagai sistem operasi bawaan laptop baru. Fiturnya persis dengan Home, namun Anda tidak diizinkan untuk mengunduh atau mengubah bahasa sistem utama setelah instalasi awal selesai.
