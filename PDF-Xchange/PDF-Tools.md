Mari kita bedah **seluruh 88 alat (*tools*)** yang ada di PDF-Tools tersebut.

Agar mudah dibaca dan tidak menjadi tumpukan teks yang membingungkan, ke-88 alat ini sudah dikelompokkan ke dalam **11 kategori resmi** sesuai bilah navigasi di sebelah kiri aplikasi Anda:

---

## 1. Create PDF (7 Alat - Pembuatan PDF)

1. **Convert Files to PDFs / Office to PDF:** Mengonversi berbagai file dokumen (Word, Excel, PPT) sekaligus menjadi PDF.
2. **Create PDF from Images:** Mengubah sekumpulan file gambar (JPG, PNG, TIFF) menjadi satu atau beberapa PDF.
3. **Create PDF from Text:** Mengubah file teks mentah (`.txt`) menjadi dokumen PDF.
4. **Create PDF from Web Pages:** Mengonversi halaman web (URL atau file `.html`) menjadi PDF.
5. **Create PDF Portfolio:** Menggabungkan berbagai jenis file berbeda ke dalam satu wadah *Portfolio PDF*.
6. **Scan to PDF:** Membuat file PDF langsung dari mesin *scanner* kertas.
7. **Build Table of Contents:** Otomatis membuatkan halaman Daftar Isi berdasarkan Bookmark dokumen.

---

## 2. Pages (29 Alat - Manipulasi & Edit Halaman)

1. **Append/Insert Pages:** Menyisipkan halaman dari PDF lain ke PDF yang sedang diproses.
2. **Crop Pages:** Memotong ukuran/margin halaman.
3. **Crop to White Margins:** Otomatis memotong margin putih yang kosong agar tampilan presisi.
4. **Delete Pages:** Menghapus halaman tertentu secara massal.
5. **Delete Duplicate Pages:** Otomatis mendeteksi dan menghapus halaman yang terduplikasi.
6. **Duplicate Pages:** Menggandakan halaman pilihan.
7. **Extract Pages:** Mengambil halaman tertentu untuk disimpan sebagai file PDF baru terpisah.
8. **Insert Empty Pages:** Menyisipkan halaman kosong di posisi yang ditentukan.
9. **Merge Pages:** Menggabungkan konten beberapa halaman menjadi satu halaman besar.
10. **Move Pages:** Pindah urutan halaman.
11. **Normalize Pages:** Menyertakan/merapikan ukuran dan orientasi halaman yang acak.
12. **Overlay PDF:** Menumpuk satu halaman PDF ke atas halaman lain (cocok untuk pasang kop surat/stempel).
13. **Rasterize Pages:** Mengubah halaman teks/vektor menjadi format gambar bitmap murni.
14. **Recolor Pages:** Mengubah skema warna isi halaman (misal: mengubah PDF warna jadi hitam-putih/grayscale).
15. **Reorder Pages:** Menyusun ulang tata letak halaman sesuai urutan yang diinginkan.
16. **Replace Pages:** Mengganti halaman lama dengan halaman dari file PDF lain.
17. **Resize Pages:** Mengubah skala ukuran kertas (misal: ubah dari A4 ke Letter atau sebaliknya).
18. **Rotate Pages:** Memutar arah rotasi halaman (90°, 180°, atau 270°).
19. **Split Pages:** Memotong satu halaman menjadi beberapa bagian (misal: memotong halaman berkolom).
20. **Split/Merge PDFs:** Memecah satu PDF besar atau menggabungkan banyak PDF sekaligus.
21. **Add Bates Numbering:** Menambahkan penomoran pengarsipan khusus hukum/arsip (*Bates Stamp*).
22. **Remove Bates Numbering:** Menghapus penomoran *Bates*.
23. **Add Header and Footer:** Menambahkan teks header/footer otomatis di setiap halaman.
24. **Remove Headers and Footers:** Menghapus teks header/footer bawaan.
25. **Set Pages Background:** Menambahkan warna atau gambar latar belakang pada halaman.
26. **Remove Pages Background:** Menghapus gambar/warna latar belakang.
27. **Add Watermark:** Menambahkan *watermark* teks atau gambar secara massal.
28. **Remove Watermarks:** Menghapus *watermark* yang ada di dalam PDF.
29. **Set Page Transitions:** Menambahkan efek transisi slide saat PDF dibuka mode *full-screen*.

---

## 3. Links (3 Alat - Pengelolaan Tautan)

1. **Add Clickable URL Links / Weblinks:** Otomatis mendeteksi teks URL (misal: `[www.site.com](https://www.site.com)`) dan membuatnya bisa diklik.
2. **Delete Links / Weblinks:** Menghapus seluruh tautan yang bisa diklik di dalam PDF.
3. **Add Links from Barcodes:** Otomatis membaca barcode di dokumen dan mengubahnya jadi hyperlink.

---

## 4. Forms (6 Alat - Formulir Interaktif)

1. **Identify Forms / Forms Recognition:** Otomatis mendeteksi bidang/kolom isian pada PDF hasil scan.
2. **Delete Form Fields:** Menghapus seluruh kolom formulir interaktif.
3. **Export Form Data:** Mengekstrak seluruh isi data formulir yang sudah diisi ke file terpisah (`.fdf` / `.csv`).
4. **Import Form Data:** Memasukkan isi data dari file luar ke dalam formulir PDF secara otomatis.
5. **Populate Forms:** Mengisi massal formulir PDF kosong menggunakan database/spreadsheet.
6. **Reset Forms:** Mengosongkan kembali seluruh kolom isian formulir.

---

## 5. Comments (6 Alat - Catatan & Anotasi)

1. **Delete All Comments:** Menghapus semua catatan, *sticky notes*, dan komentar.
2. **Delete Markup Annotations:** Menghapus garis bawah, *highlight*, atau coretan teks.
3. **Export Comments:** Mengambil seluruh komentar dan menyimpannya ke file terpisah.
4. **Import Comments:** Memasukkan komentar dari file eksternal ke dalam PDF.
5. **Flatten Comments and Fields:** Mengunci komentar/form agar menyatu permanen dengan latar belakang dokumen (tidak bisa diedit lagi).
6. **Summarize Comments:** Otomatis membuat halaman lembar ringkasan dari seluruh komentar yang ada.

---

## 6. Bookmarks (7 Alat - Navigasi Dokumen)

1. **Add/Edit Bookmarks:** Menambah atau mengubah struktur penanda halaman (*bookmark*).
2. **Clear Bookmarks:** Menghapus semua *bookmark* di dokumen.
3. **Export Bookmarks:** Mengekstrak struktur *bookmark* ke file terpisah.
4. **Export Bookmarks to Text File:** Menyimpan *bookmark* ke format dokumen teks biasa (`.txt`).
5. **Import Bookmarks:** Memasukkan *bookmark* dari file luar ke PDF.
6. **Find and Replace Bookmark Text:** Mencari dan mengganti kata pada nama *bookmark* secara sekaligus.
7. **Generate Bookmarks from Page Text:** Otomatis membuatkan *bookmark* berdasarkan judul/teks halaman.

---

## 7. Protection (9 Alat - Keamanan & Privasi)

1. **Secure PDF / Encryption:** Memberi password buka (*Open*) atau membatasi hak akses print/edit (*Permissions*).
2. **Apply Redaction:** Mengunci pemblokiran informasi sensitif secara permanen.
3. **Redact Regions:** Menentukan area koordinat spesifik untuk ditutupi/di-redact.
4. **Find and Redact:** Mencari kata tertentu (misal: nomor rekening/NIK) dan langsung membloknya hitam.
5. **Certify PDFs:** Mengamankan dokumen dengan sertifikat keaslian digital.
6. **Sign Document:** Membubuhi tanda tangan digital berbasis *Digital ID*.
7. **Clear All Digital Signatures:** Menghapus seluruh tanda tangan digital dari dokumen.
8. **Timestamp PDFs:** Menambahkan stempel waktu resmi dari server *Timestamp Authority* (TSA).
9. **Sanitize Document:** Membersihkan dokumen dari metadata tersembunyi, jejak revisi, dan informasi sensitif.

---

## 8. Optimize PDF (4 Alat - Kompresi & Kualitas)

1. **Optimize PDF:** Memproses kompresi menyeluruh agar ukuran file PDF jadi jauh lebih kecil.
2. **Recompress Images:** Khusus menurunkan kualitas/ukuran file gambar di dalam PDF.
3. **Enhance Scanned Pages:** Membersihkan bintik/noda hitam hasil scan serta meluruskan posisi halaman miring.
4. **OCR Pages:** Mengubah PDF hasil scan (format gambar) menjadi teks yang bisa dicari/dikutip (*Searchable Text*).

---

## 9. PDF Standard (3 Alat - Standardisasi ISO)

1. **Convert to PDF/A:** Mengonversi PDF ke standar pengarsipan jangka panjang (*ISO PDF/A*).
2. **Convert to PDF/X:** Mengonversi PDF ke standar percetakan profesional (*ISO PDF/X*).
3. **Discard Special PDF-Standard:** Menghapus atribut standar PDF/A atau PDF/X agar kembali jadi PDF biasa.

---

## 10. Export PDF (7 Alat - Konversi Keluar)

1. **Export PDF to Microsoft Word Document:** Mengubah PDF kembali menjadi file Word (`.docx`).
2. **Export PDF to Microsoft Excel Spreadsheet:** Mengubah tabel PDF kembali ke Excel (`.xlsx`).
3. **Export PDF to Microsoft PowerPoint Presentation:** Mengubah PDF ke slide PPT (`.pptx`).
4. **Export PDF to Plain Text:** Mengambil seluruh teks dokumen ke file teks biasa (`.txt`).
5. **Export PDF to Images:** Mengubah setiap halaman PDF menjadi file gambar (JPG, PNG, TIFF).
6. **Extract Images from PDF:** Menarik/menyedot semua file gambar yang tertanam di dalam PDF.
7. **Extract Content from PDF:** Mengambil isi konten teks/gambar dari PDF secara terpisah.

---

## 11. Advanced (7 Alat - Fitur Lanjutan & Otomasi)

1. **Add Attachments:** Menempelkan file lampiran (ZIP, DOCX, dll) ke dalam file PDF.
2. **Extract Attachments:** Mengambil file lampiran yang ada di dalam PDF.
3. **Add Barcode:** Menambahkan kode *barcode* atau *QR code* otomatis.
4. **Change Document Properties:** Mengubah metadata file (Judul, Pengarang, Subjek, Kata Kunci).
5. **Convert Colors:** Mengubah profil warna dokumen (misal: dari RGB ke CMYK untuk cetak).
6. **Run JavaScript:** Menjalankan skrip perintah JavaScript kustom untuk fungsi otomatisasi khusus.
7. **Send E-Mail:** Otomatis mengirimkan PDF hasil konversi/proses ke alamat e-mail via SMTP/MAPI.
