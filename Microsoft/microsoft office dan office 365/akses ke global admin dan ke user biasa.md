## **3. Simulasi langsung saat kamu datang ke kantor customer**

Misalnya kamu membawa laptop teknisi dan customer punya 3 karyawan.

**TAHAP 1 — Laptop teknisi**

**Buka browser**

Masuk ke `admin.microsoft.com`

Login:\
`admin@kum.onmicrosoft.com`

Global Admin

**TAHAP 2 — Buat akun user**

Di Admin Center:

`Users → Active users → Add a user`

Buat akun:

| Nama | Akun                      |
| ---- | ------------------------- |
| Budi | budi\@kum.onmicrosoft.com |
| Andi | andi\@kum.onmicrosoft.com |
| Sari | sari\@kum.onmicrosoft.com |

Assign lisensi Microsoft 365 Apps for Business kepada masing-masing.

**TAHAP 3 — Pindah ke laptop user**

Misalnya kamu sedang mengerjakan laptop Budi.

Buka browser:

`m365.cloud.microsoft/apps`

Login sebagai:

`budi@kum.onmicrosoft.com`

Klik:

`Install apps → Microsoft 365 apps`

Download `OfficeSetup.exe`.

Jalankan installer dan tunggu sampai selesai.

**TAHAP 4 — Aktivasi Office**

Buka Word.

Login menggunakan:

`budi@kum.onmicrosoft.com`

Pastikan status Office sudah aktif.

Selesai

## **4. Perbedaan akun dan portal**

| Keterangan     | Global Admin               | User                           |
| -------------- | -------------------------- | ------------------------------ |
| Link           | admin.microsoft.com        | m365.cloud.microsoft/apps      |
| Akun           | admin\@kum.onmicrosoft.com | budi\@kum.onmicrosoft.com      |
| Fungsi         | Kelola tenant              | Install dan menggunakan Office |
| Buat user      | Bisa                       | Tidak                          |
| Assign lisensi | Bisa                       | Tidak                          |

**Satu hal penting:** Jangan sampai user login ke Office menggunakan akun Global Admin. Gunakan akun masing-masing yang sudah mendapat lisensi.

Jadi alurnya sederhana: **Kamu mengelola akun dan lisensi dari Admin Center, sedangkan karyawan menggunakan portal Microsoft 365 untuk download Office dan akun masing-masing untuk aktivasi.**
